# Sistema de Gestão de Projetos e Equipes

Projeto desenvolvido em Java utilizando os conceitos de Programação Orientada a Objetos (POO). O sistema foi criado com o objetivo de auxiliar no gerenciamento de projetos e equipes de forma simples e organizada.

## Funcionalidades

* Cadastro de projetos
* Listagem de projetos
* Estrutura orientada a objetos
* Menu interativo no console

## Tecnologias Utilizadas

* Java
* IntelliJ IDEA
* GitHub
* Programação Orientada a Objetos

## Estrutura do Projeto

* Main.java
* Projeto.java
* Tarefa.java
* Colaborador.java

## Objetivo do Projeto

Aplicar os conceitos fundamentais da linguagem Java e da Programação Orientada a Objetos no desenvolvimento de um sistema simples de gestão de projetos.
